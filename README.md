# Python Fundamentals 🐍

A bilingual Python learning project for Persian-speaking and international learners.

## Choose your language

- **[English version](english/README.md)** — lessons, examples, exercises, and documentation in English.
- **[نسخه فارسی](persian/README.md)** — ترجمه فارسی درس‌ها، مثال‌ها، تمرین‌ها و مستندات.

Both learning tracks follow the same chapter structure and sequence. Python identifiers and filenames stay consistent; explanations, comments, prompts, and exercise statements are localized.

## Synchronization policy

When a lesson or exercise changes in one language, update its counterpart in the other language. Keep paths and Python identifiers aligned so the two tracks remain easy to compare.
