# Python Fundamentals — English Track

A structured, hands-on Python curriculum. Follow the chapters in order; the Persian track mirrors the same concepts and exercise IDs.

## Learning path
| Order | Chapter | Focus |
|---|---|---|
| 01 | [Python Foundations](chapters/01-python-foundations/) | Variables, types, input/output, conversion, operators, strings |
| 02 | [Conditions and Loops](chapters/02-conditions-and-loops/) | Branching, loops, counters, accumulators, patterns |
| 03 | [Data Structures](chapters/03-data-structures/) | Lists, tuples, sets, dictionaries, nested data, comprehensions |
| 04 | [Functions](chapters/04-functions/) | Definitions, parameters, return, flexible arguments, scope, recursion |
| 05 | [Modules, Exceptions, and Debugging](chapters/05-modules-and-debugging/) | Imports, standard library, exceptions, debugging, virtual environments |

## Start here
1. Read the chapter README.
2. Run its numbered Python files in order.
3. Change example values and predict the output.
4. Solve the five matching problems in [PRACTICE.md](PRACTICE.md).
5. Track your own study in [PROGRESS.md](PROGRESS.md).
