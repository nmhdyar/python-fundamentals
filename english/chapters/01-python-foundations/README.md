# Chapter 01 — Python Foundations

This chapter establishes the core building blocks used in every Python program.

## Learning objectives

By the end of this chapter, you should be able to:

- Create variables and follow Python naming conventions.
- Recognize the main built-in data types.
- Read input and display formatted output.
- Convert values between common data types safely.
- Use arithmetic, comparison, logical, and assignment operators.
- Work with strings, indexing, slicing, and common string methods.

## How to study

1. Read the short concept notes at the top of each file.
2. Run Example 1 and inspect its output.
3. Run Example 2 and change some values to see what happens.
4. Solve the practice tasks without looking at the solution first.

> A topic is not mastered by reading code. Run it, modify it, and explain why it works.
