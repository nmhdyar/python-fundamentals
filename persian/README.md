## راهنمای Type Hint (راهنمای نوع)

پایتون یک زبان با نوع‌دهی پویا است؛ یعنی نوع به مقدار تعلق دارد و یک نام متغیر می‌تواند در طول برنامه به مقادیر با نوع‌های متفاوت اشاره کند. **Type Hint** یا «راهنمای نوع» مشخص می‌کند که انتظار داریم یک متغیر، پارامتر تابع یا مقدار بازگشتی چه نوعی داشته باشد.

### مشخص کردن نوع متغیرها

```python
name: str = "Nima"
age: int = 20
height: float = 1.82
is_learning: bool = True
middle_name: str | None = None
scores: list[int] = [18, 20, 16]
prices: dict[str, float] = {"coffee": 2.5}
```

عبارت بعد از دونقطه نوع مورد انتظار را مشخص می‌کند. مقداردهی با علامت `=` همچنان به شکل عادی انجام می‌شود.

### مشخص کردن نوع پارامتر و خروجی تابع

```python
def calculate_total(price: float, quantity: int) -> float:
    return price * quantity

def show_message(message: str) -> None:
    print(message)
```

- نوع کنار پارامتر، نوع مورد انتظار ورودی تابع را نشان می‌دهد.
- علامت `->` نوع خروجی تابع را مشخص می‌کند.
- اگر تابع مقدار معناداری برنگرداند، از `-> None` استفاده می‌کنیم.

### نوع‌های پرکاربرد

| راهنمای نوع | معنی |
|---|---|
| `int` | عدد صحیح |
| `float` | عدد اعشاری |
| `str` | رشته یا متن |
| `bool` | مقدار درست یا نادرست |
| `None` | نبود مقدار |
| `str | None` | رشته یا None |
| `list[int]` | لیستی از اعداد صحیح |
| `dict[str, float]` | دیکشنری با کلیدهای رشته‌ای و مقادیر اعشاری |

### نکته‌های مهم

۱. Type Hint مقدار را تبدیل نمی‌کند. تابع `input()` همچنان خروجی از نوع `str` دارد؛ برای دریافت عدد باید از `int()` یا `float()` استفاده کنیم.

۲. پایتون به‌صورت معمول Type Hintها را هنگام اجرای برنامه اجباری نمی‌کند. این راهنماها بیشتر به خوانایی کد، تکمیل خودکار و ابزارهای بررسی ایستا کمک می‌کنند.

۳. Type Hint جایگزین اعتبارسنجی ورودی یا تست برنامه نیست.

۴. هنگام تغییر مقدار یک متغیر، نوع جدید باید با راهنمای نوع آن سازگار باشد.

۵. در حلقه `for` نوع مجموعه یا داده قابل پیمایش را مشخص می‌کنیم؛ پایتون معمولاً نوع متغیر حلقه را خودش تشخیص می‌دهد.

۶. ساختار `X | None` به پایتون نسخه ۳.۱۰ یا جدیدتر نیاز دارد.
