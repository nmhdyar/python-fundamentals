# مبانی پایتون — مسیر فارسی

## نقشه مسیر یادگیری

| ۰۱ | [مبانی پایتون](chapters/01-python-foundations/) | متغیرها، انواع داده، ورودی و خروجی، تبدیل نوع، عملگرها و رشته‌ها |
| ۰۲ | [شرط‌ها و حلقه‌ها](chapters/02-conditions-and-loops/) | شرط، حلقه، شمارنده، انباره و الگوها |

| ۰۴ | [توابع](chapters/04-functions/) | تعریف تابع، پارامتر، خروجی، آرگومان متغیر، محدوده و بازگشت |
| ۰۵ | [ماژول‌ها، استثناها و اشکال‌زدایی](chapters/05-modules-and-debugging/) | import، کتابخانه استاندارد، استثنا، عیب‌یابی و محیط مجازی |

## از کجا شروع کنم؟
۱. README فصل را بخوان.
۲. فایل‌های شماره‌گذاری‌شده پایتون را به‌ترتیب اجرا کن.
۳. مقدارهای مثال را تغییر بده و خروجی را پیش‌بینی کن.
۴. پنج تمرین همان فصل را در [PRACTICE.md](PRACTICE.md) حل کن.
۵. روند مطالعه خودت را در [PROGRESS.md](PROGRESS.md) ثبت کن.
