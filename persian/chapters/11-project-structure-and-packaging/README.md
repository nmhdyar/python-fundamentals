# فصل 11 — ساختار پروژه و بسته‌بندی

> وضعیت: پیش‌نویس جفت‌شده  
> نسخه انگلیسی: [Chapter 11 — Project Structure & Packaging](../../../english/chapters/11-project-structure-and-packaging/README.md)

## ۱. معرفی فصل
برنامه‌های چندماژولی را سازمان‌دهی کن، وابستگی‌ها را مدیریت کن و پروژه را برای استفاده مجدد مطمئن آماده کن.

## ۲. اهداف یادگیری
در پایان این فصل می‌توانی:
- مفاهیم زیر را توضیح بدهی و کاربرد هرکدام را تشخیص بدهی.
- الگوها را در برنامه‌های کوچک و قابل اجرا پیاده‌سازی کنی.
- راه‌حلی روشن انتخاب کنی و مزایا و محدودیت‌هایش را توضیح بدهی.
- حالت‌های عادی، مرزی و نامعتبر را آزمایش کنی.

## ۳. پیش‌نیازها
فصل‌های ۰۱ تا ۱۰؛ import، محیط مجازی، شی‌گرایی، تست و کار با فایل.

## ۴. درس‌ها
1. چیدمان پروژه و جداسازی مسئولیت‌ها
2. Package و فایل `__init__.py`
3. Import مطلق و نسبی
4. محیط مجازی و جداسازی وابستگی‌ها
5. `requirements.txt` و نسخه‌های تثبیت‌شده
6. آشنایی با `pyproject.toml`
7. سطوح Logging و Handlerها
8. تنظیمات و متغیرهای محیطی
9. نقطه ورود و مبانی خط فرمان
10. مفاهیم بسته‌بندی و انتشار

## ۵. مثال‌های حل‌شده
فایل‌های درس، مثال‌های حل‌شده و قابل اجرا هستند. پیش از اجرا، هر دستور را دنبال کن و خروجی را پیش‌بینی کن؛ سپس یک ورودی یا تصمیم طراحی را تغییر بده و نتیجه را مقایسه کن.

## ۶. اشتباهات رایج
- ساخت یک ماژول بسیار بزرگ؛ ثبت رمزها در Git؛ نصب سراسری بسته‌ها؛ ثبت اطلاعات محرمانه در Log یا بلعیدن استثنا؛ اشتباه گرفتن چیدمان کد با فراداده انتشار.
- کپی‌کردن یک الگو بدون درک قرارداد یا اثرات جانبی آن.
- نادیده‌گرفتن اعتبارسنجی و حالت‌های مرزی.

## ۷. تمرین‌ها
تمرین‌های CH11-EX01, CH11-EX02, CH11-EX03, CH11-EX04, CH11-EX05 را در فایل [PRACTICE.md](../../PRACTICE.md) حل کن.

**پروژه فصل:** یک اسکریپت انبارداری تک‌فایلی را به Packageای با تنظیمات، Logging، تست و نقطه ورود مستند تبدیل کن.

## ۸. جمع‌بندی فصل
فهرست درس‌ها را مرور کن و ایده اصلی هر درس را با زبان خودت توضیح بده. مثال‌ها را پس از تغییر داده‌ها یا فرض‌ها دوباره اجرا کن.

## ۹. خودارزیابی
- [ ] می‌توانم واژگان اصلی فصل را توضیح بدهم.
- [ ] می‌توانم بدون کپی‌کردن درس، مثال کوچکی بنویسم.
- [ ] دست‌کم دو حالت خطا یا شکست رایج را تشخیص می‌دهم.
- [ ] می‌توانم توضیح بدهم چرا راه‌حل من مناسب است.

## ۱۰. واژه‌نامه
| اصطلاح انگلیسی | معنی یا تعریف |
|---|---|
| Project | موضوع اصلی این فصل. |
| Implementation | پیاده‌سازی؛ بیان یک ایده به‌شکل کد اجرایی. |
| Edge case | حالت مرزی؛ ورودی یا شرایط غیرمعمول اما مهم. |
| Trade-off | موازنه؛ انتخابی که یک ویژگی را بهتر و ویژگی دیگری را محدود می‌کند. |
