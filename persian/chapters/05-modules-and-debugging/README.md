# فصل ۰۵ — ماژول‌ها، استثناها و اشکال‌زدایی

## ۱. معرفی فصل
با بزرگ‌ترشدن برنامه، بهتر است کد را به ماژول‌های متمرکز تقسیم کنیم. در این فصل همچنین با کتابخانه استاندارد پایتون، مدیریت استثناها و روند منظم اشکال‌زدایی آشنا می‌شویم.

## ۲. اهداف یادگیری
- توضیح مفهوم ماژول و روش‌های رایج import.
- محافظت از نقطه شروع اسکریپت با `if __name__ == "__main__":`.
- استفاده از چند ماژول کتابخانه استاندارد.
- تشخیص خطاهای نحوی و استثناهای زمان اجرا.
- مدیریت خطاهای قابل پیش‌بینی با نوع استثنای مشخص.
- ایجاد استثنا در صورت دریافت ورودی نامعتبر.
- توضیح روند پایه استفاده از Package و محیط مجازی.
- اشکال‌زدایی با بازتولید، محدودکردن، بررسی و تأیید مشکل.

## ۵. مثال‌های حل‌شده
مثال‌ها واردکردن ماژول، استفاده از ابزارهای کتابخانه استاندارد، مدیریت خطای تبدیل، اعتبارسنجی تعداد و ساخت محیط جداگانه برای پروژه را نشان می‌دهند.

## ۶. اشتباهات رایج
- نام‌گذاری فایل با نام یک ماژول استاندارد مانند `random.py`.
- استفاده از `except:` بدون مشخص‌کردن نوع استثنا.
- گرفتن استثنا و نادیده‌گرفتن بی‌صدای آن.
- استفاده از استثنا برای کنترل جریان عادی برنامه.
- فراموش‌کردن اینکه `finally` چه استثنا رخ بدهد چه ندهد اجرا می‌شود.
- نصب سراسری پکیج‌ها در حالی که پروژه به محیط مجزا نیاز دارد.

## ۷. تمرین‌ها
تمرین‌های `CH05-EX01` تا `CH05-EX05` را در فایل تمرین اصلی مخزن حل کن.

## ۸. جمع‌بندی
ماژول‌ها کد را سازمان‌دهی می‌کنند؛ کتابخانه استاندارد ابزارهای آماده فراهم می‌کند؛ استثناها خطاها را گزارش می‌کنند و مدیریت‌کننده‌ها به برنامه اجازه پاسخ‌دادن به خطاهای قابل پیش‌بینی را می‌دهند. اشکال‌زدایی فرایندی منظم است، نه ویرایش تصادفی کد.

## ۹. خودارزیابی
- [ ] می‌توانم ماژول را import کنم و main guard را توضیح بدهم.
- [ ] می‌توانم یک استثنای مشخص را بدون پنهان‌کردن خطاهای نامرتبط مدیریت کنم.
- [ ] می‌توانم ورودی را اعتبارسنجی و استثنای معنادار ایجاد کنم.
- [ ] می‌توانم محیط مجازی بسازم و فعال کنم.

## ۱۰. واژه‌نامه
| اصطلاح انگلیسی | معنی |
|---|---|
| Module | فایل پایتونی که می‌توان آن را import کرد |
| Package | روشی برای سازمان‌دهی ماژول‌های مرتبط |
| Exception | شیئی که خطای زمان اجرا را نمایش می‌دهد |
| Traceback | تاریخچه فراخوانی‌ها هنگام مدیریت‌نشدن استثنا |
| Debugging | پیدا و اصلاح‌کردن علت یک مشکل |
| Virtual environment | محیط پایتون جداگانه برای یک پروژه |
