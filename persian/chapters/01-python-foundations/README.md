# فصل ۰۱ — مبانی پایتون

این فصل پایه‌های اصلی مورد استفاده در برنامه‌های پایتون را معرفی می‌کند.

## اهداف یادگیری

در پایان این فصل باید بتوانی:
- متغیر بسازی و قواعد نام‌گذاری پایتون را رعایت کنی.
- انواع داده اصلی و داخلی پایتون را تشخیص بدهی.
- از کاربر ورودی بگیری و خروجی قالب‌بندی‌شده نمایش بدهی.
- مقادیر را بین انواع داده رایج تبدیل کنی.
- از عملگرهای حسابی، مقایسه‌ای، منطقی و انتساب استفاده کنی.
- با رشته‌ها، اندیس‌گذاری، برش و متدهای رایج رشته کار کنی.
