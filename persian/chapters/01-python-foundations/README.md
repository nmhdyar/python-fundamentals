# فصل ۰۱ — مبانی پایتون

> وضعیت: پیش‌نویس جفت‌شده
> نسخه انگلیسی: [Chapter 01 — Python Foundations](../../../english/chapters/01-python-foundations/README.md)

## ۱. معرفی فصل
در این فصل دستور زبان و مقدارهای پایه‌ای پایتون را می‌شناسیم: متغیرها، نوع‌های داخلی، ورودی و خروجی، تبدیل نوع، عملگرها و رشته‌ها.

## ۲. اهداف یادگیری
در پایان فصل می‌توانی:
- با نام‌گذاری روشن و سبک `snake_case` متغیر بسازی.
- مقدارهای `int`، `float`، `str`، `bool` و `None` را تشخیص بدهی.
- با `input()` ورودی بگیری و با `print()` و f-string خروجی قالب‌بندی کنی.
- ورودی را پیش از محاسبه به نوع عددی مناسب تبدیل کنی.
- از عملگرهای حسابی، مقایسه‌ای، منطقی و انتساب استفاده کنی.
- رشته‌ها را اندیس‌گذاری و برش بدهی و متدهای رایج آن‌ها را به کار ببری.

## ۳. پیش‌نیازها
دانش قبلی پایتون لازم نیست. آشنایی پایه با رایانه و توانایی اجرای یک فایل پایتون کافی است.

## ۵. مثال‌های حل‌شده
فایل‌های درس مثال‌هایی درباره اطلاعات شخصی، پیام قالب‌بندی‌شده، تبدیل عددی، محاسبات و پاک‌سازی رشته دارند. هر فایل را می‌توان مستقل اجرا کرد.

## ۶. اشتباهات رایج
- استفاده از خروجی `input()` در محاسبه، بدون تبدیل نوع.
- اشتباه گرفتن `=` (انتساب) با `==` (مقایسه).
- انتظار موفقیت `int("3.5")`.
- فراموش‌کردن اینکه اندیس رشته از صفر شروع می‌شود.
- تصور اینکه متدهای رشته، مقدار اصلی را درجا تغییر می‌دهند.

## ۸. جمع‌بندی
متغیر نامی برای ارجاع به یک مقدار است. نوع داده، ویژگی‌های مقدار و عملیات مجاز روی آن را مشخص می‌کند. ورودی و خروجی ارتباط برنامه با کاربر را فراهم می‌کنند. تبدیل نوع، نوع مقدار را تغییر می‌دهد؛ عملگرها محاسبه و مقایسه انجام می‌دهند و رشته‌ها ابزار کار با متن را فراهم می‌کنند.

## ۹. خودارزیابی
- [ ] تفاوت متغیر و مقدار را توضیح می‌دهم.
- [ ] نوع‌های اصلی داده را تشخیص می‌دهم.
- [ ] پیش از محاسبه، ورودی عددی را تبدیل می‌کنم.
- [ ] می‌توانم خروجی را قالب‌بندی و عملیات پایه رشته‌ای را اجرا کنم.

## ۱۰. واژه‌نامه
| اصطلاح انگلیسی | معنی |
|---|---|
| Variable | متغیر؛ نامی که به یک مقدار اشاره می‌کند |
| Data type | نوع داده؛ دسته‌بندی مقدار و عملیات آن |
| Type conversion | تبدیل نوع؛ ساخت مقدار با نوعی دیگر |
| Expression | عبارت؛ کدی که به یک مقدار ارزیابی می‌شود |
| String | رشته؛ دنباله‌ای از نویسه‌های متنی |
