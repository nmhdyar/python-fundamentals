# فصل ۰۳ — ساختارهای داده

> وضعیت: در حال بازبینی — نسخه‌های فارسی و انگلیسی جفت شده‌اند
> نسخه انگلیسی: [Chapter 03 — Data Structures](../../../english/chapters/03-data-structures/README.md)

## ۱. معرفی فصل
در این فصل یاد می‌گیریم داده‌ها را چگونه در مجموعه‌ها ذخیره، سازمان‌دهی، بازیابی و تبدیل کنیم. انتخاب ساختار داده باید بر اساس عملیات موردنیاز و ویژگی‌های مورد انتظار برنامه باشد.

## ۲. اهداف یادگیری
در پایان فصل می‌توانی:
- اعضای لیست را بسازی، بخوانی، تغییر بدهی و حذف کنی.
- کاربرد تاپل و تغییرناپذیر بودن آن را توضیح بدهی.
- برای نگهداری مقادیر یکتا و عملیات مجموعه‌ای از set استفاده کنی.
- داده‌های کلید-مقدار را در دیکشنری ذخیره و بازیابی کنی.
- با مجموعه‌های تو در تو به‌شکل امن کار کنی.
- از List Comprehension و Dictionary Comprehension استفاده کنی.

## ۳. پیش‌نیازها
فصل‌های ۰۱ و ۰۲: متغیرها، انواع داده، رشته‌ها، شرط‌ها، حلقه‌ها و توابع ساده‌ای مانند `len()` و `range()`.

## ۵. مثال‌های حل‌شده
فایل‌های درس مثال‌های قابل اجرا درباره فهرست خرید، مختصات، برچسب‌های یکتا، فهرست محصولات، اطلاعات دانشجویان و تبدیل داده‌ها دارند.

## ۶. اشتباهات رایج
- دسترسی به اندیس یا کلیدی که وجود ندارد.
- تغییر یک مجموعه هنگام پیمایش همان مجموعه.
- انتظار امکان انتساب به عضو تاپل.
- استفاده از لیست یا دیکشنری تغییرپذیر به‌عنوان عضو set یا کلید دیکشنری.
- اشتباه گرفتن `dict.get()` با دسترسی مستقیم.
- نوشتن کامپرهنشنی که از یک حلقه معمولی پیچیده‌تر و ناخواناتر است.

## ۷. تمرین‌ها
تمرین‌های `CH03-EX01` تا `CH03-EX05` را در فایل تمرین اصلی مخزن حل کن. صورت مسئله‌ها باید در نسخه انگلیسی و فارسی متناظر باشند.

## ۸. جمع‌بندی
لیست مرتب و تغییرپذیر است؛ تاپل مرتب و تغییرناپذیر است؛ مجموعه مقادیر یکتای هش‌پذیر نگه می‌دارد؛ دیکشنری کلیدهای یکتا را به مقدارها نگاشت می‌کند. کامپرهنشن‌ها برای ساخت مجموعه از داده‌های قابل پیمایش به کار می‌روند.

## ۹. خودارزیابی
- [ ] می‌توانم بین list، tuple، set و dict انتخاب کنم.
- [ ] می‌توانم توضیح بدهم یک عملیات مجموعه را تغییر می‌دهد یا نه.
- [ ] می‌توانم به داده‌های تو در تو به‌شکل امن دسترسی پیدا کنم.
- [ ] می‌توانم یک حلقه ساده را به کامپرهنشن خوانا تبدیل کنم.

## ۱۰. واژه‌نامه
| اصطلاح انگلیسی | معنی |
|---|---|
| Mutable | تغییرپذیر؛ پس از ساخت قابل تغییر است |
| Immutable | تغییرناپذیر؛ پس از ساخت قابل تغییر نیست |
| Iterable | شیئی که می‌توان روی اعضای آن پیمایش کرد |
| Hashable | دارای هش پایدار؛ قابل استفاده به‌عنوان عضو set یا کلید دیکشنری |
| Comprehension | ساختار فشرده برای تولید یک مجموعه |
