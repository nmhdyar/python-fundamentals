# فصل ۰۴ — توابع

> وضعیت: تأییدشده — نسخه‌های فارسی و انگلیسی جفت شده‌اند
> نسخه انگلیسی: [Chapter 04 — Functions](../../../english/chapters/04-functions/README.md)

## ۱. معرفی فصل
تابع، رفتاری قابل استفاده مجدد را پشت یک رابط روشن قرار می‌دهد. در این فصل از توابع ساده شروع می‌کنیم و به آرگومان‌های انعطاف‌پذیر، محدوده متغیرها، Lambda و بازگشت می‌رسیم.

## ۲. اهداف یادگیری
- تعریف و فراخوانی تابع.
- تشخیص تفاوت پارامتر و آرگومان.
- برگرداندن مقدار و اشتباه نگرفتن `print()` با `return`.
- استفاده از آرگومان‌های پیش‌فرض و نام‌دار.
- دریافت تعداد متغیر آرگومان‌های موقعیتی و کلیدواژه‌ای.
- توضیح محدوده محلی و سراسری.
- نوشتن Lambdaهای کوچک و درک مفهوم بازگشت.
- نوشتن Docstring و Type Hint مفید.

## ۳. پیش‌نیازها
فصل‌های ۰۱ تا ۰۳: متغیرها، شرط‌ها، حلقه‌ها، رشته‌ها و ساختارهای داده.

## ۵. مثال‌های حل‌شده
مثال‌ها شامل پیام خوشامدگویی قابل استفاده مجدد، محاسبه قیمت، پیام قابل تنظیم، خلاصه‌سازی انعطاف‌پذیر، مرتب‌سازی رکوردها و توابع بازگشتی شمارش معکوس و فاکتوریل هستند.

## ۶. اشتباهات رایج
- فراموش‌کردن پرانتز هنگام فراخوانی تابع.
- انتظار داشتن مقدار قابل استفاده از `print()` به‌جای `return`.
- استفاده از شیء تغییرپذیر به‌عنوان مقدار پیش‌فرض پارامتر.
- تغییر وضعیت سراسری در حالی که متغیر محلی کافی است.
- نوشتن تابع بازگشتی بدون حالت پایه.
- افزودن پارامترهای زیاد به‌جای طراحی رابط روشن.

## ۸. جمع‌بندی
تابع نام، پارامترهای اختیاری، بدنه و در صورت نیاز مقدار بازگشتی دارد. توابع کوچک با ورودی و خروجی روشن بنویس. آرگومان‌های انعطاف‌پذیر را فقط زمانی به کار ببر که رابط تابع را بهتر کنند.

## ۹. خودارزیابی
- [ ] می‌توانم تابعی بنویسم که مقدار برگرداند.
- [ ] تفاوت پارامتر و آرگومان را می‌دانم.
- [ ] می‌توانم مقدار پیش‌فرض امن انتخاب کنم.
- [ ] محدوده محلی و حالت پایه بازگشت را درک می‌کنم.

## ۱۰. واژه‌نامه
| اصطلاح انگلیسی | معنی |
|---|---|
| Function | تابع؛ بلوک کد قابل استفاده مجدد |
| Parameter | نامی که در تعریف تابع می‌آید |
| Argument | مقداری که هنگام فراخوانی به تابع داده می‌شود |
| Return value | نتیجه‌ای که تابع به فراخواننده برمی‌گردانَد |
| Scope | محدوده‌ای که در آن می‌توان به یک نام دسترسی داشت |
| Recursion | فراخوانی یک تابع توسط خودش |
