# فصل 07 — کار با فایل و ماندگاری داده

> وضعیت: پیش‌نویس جفت‌شده  
> نسخه انگلیسی: [Chapter 07 — File Handling & Data Persistence](../../../english/chapters/07-file-handling-and-data-persistence/README.md)

## ۱. معرفی فصل
داده‌های ساختاریافته را به‌شکل امن بخوان، بنویس و بین اجراهای برنامه نگهداری کن.

## ۲. اهداف یادگیری
در پایان این فصل می‌توانی:
- مفاهیم زیر را توضیح بدهی و کاربرد هرکدام را تشخیص بدهی.
- الگوها را در برنامه‌های کوچک و قابل اجرا پیاده‌سازی کنی.
- راه‌حلی روشن انتخاب کنی و مزایا و محدودیت‌هایش را توضیح بدهی.
- حالت‌های عادی، مرزی و نامعتبر را آزمایش کنی.

## ۳. پیش‌نیازها
فصل‌های ۰۱ تا ۰۵؛ رشته‌ها، دیکشنری‌ها، استثناها و آشنایی مقدماتی با pathlib.

## ۴. درس‌ها
1. فایل متنی و حالت‌های بازکردن فایل
2. خواندن با `read`، `readline` و پیمایش
3. نوشتن و افزودن به انتهای فایل
4. مدیر زمینه و `with`
5. مسیرها با `pathlib`
6. سریال‌سازی و بازیابی JSON
7. خواندن و نوشتن CSV
8. نکات Encoding و Newline
9. استثناهای فایل و به‌روزرسانی امن

### فایل‌های درس قابل اجرا

|---|---|
| [01_text_files_and_paths.py](01_text_files_and_paths.py) | با pathlib و پوشه موقت، یک فایل متنی UTF-8 را امن بنویس و بخوان. |
| [02_json_and_csv.py](02_json_and_csv.py) | رکوردهای ساختاریافته را به JSON تبدیل کن و با ماژول csv خروجی جدولی بگیر. |

## ۵. مثال‌های حل‌شده
فایل‌های درس، مثال‌های حل‌شده و قابل اجرا هستند. پیش از اجرا، هر دستور را دنبال کن و خروجی را پیش‌بینی کن؛ سپس یک ورودی یا تصمیم طراحی را تغییر بده و نتیجه را مقایسه کن.

## ۶. اشتباهات رایج
- نبستن فایل؛ بازنویسی ناخواسته به‌جای افزودن؛ تصور حفظ مستقیم اشیای دلخواه پایتون در JSON؛ نادیده‌گرفتن Encoding و خطای نبود فایل.
- کپی‌کردن یک الگو بدون درک قرارداد یا اثرات جانبی آن.
- نادیده‌گرفتن اعتبارسنجی و حالت‌های مرزی.

## ۷. تمرین‌ها
تمرین‌های CH07-EX01, CH07-EX02, CH07-EX03, CH07-EX04, CH07-EX05 را در فایل [PRACTICE.md](../../PRACTICE.md) حل کن.

**پروژه فصل:** مدیریت مخاطبانی بساز که اطلاعات را از JSON بارگذاری و ذخیره کند، رکوردها را اعتبارسنجی کند و گزارش CSV خروجی بدهد.

## ۸. جمع‌بندی فصل
فهرست درس‌ها را مرور کن و ایده اصلی هر درس را با زبان خودت توضیح بده. مثال‌ها را پس از تغییر داده‌ها یا فرض‌ها دوباره اجرا کن.

## ۹. خودارزیابی
- [ ] می‌توانم واژگان اصلی فصل را توضیح بدهم.
- [ ] می‌توانم بدون کپی‌کردن درس، مثال کوچکی بنویسم.
- [ ] دست‌کم دو حالت خطا یا شکست رایج را تشخیص می‌دهم.
- [ ] می‌توانم توضیح بدهم چرا راه‌حل من مناسب است.
