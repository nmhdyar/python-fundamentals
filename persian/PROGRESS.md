# مبانی پایتون — نقطه پیگیری یادگیری

این فایل بین موجودبودن محتوا در مخزن و تسلط شخصی تفاوت می‌گذارد. هر مبحث را فقط پس از مطالعه و تمرین کامل علامت بزن.

## وضعیت محتوای دوره
| فصل‌ها | تمرکز | وضعیت مخزن |
|---|---|---|
| ۰۱ تا ۰۵ | مبانی | محتوای دوزبانه موجود |
| ۰۲ | تکمیل کنترل حلقه | درس‌های دوزبانه break و continue |
| ۰۶ تا ۰۸ | پایتون متوسط | پیش‌نویس فصل‌ها و مثال‌های اجرایی دوزبانه |
| ۰۹ تا ۱۱ | پایتون پیشرفته | پیش‌نویس فصل‌ها و مثال‌های اجرایی دوزبانه |

## مرور شخصی
- [ ] کنترل حلقه و توابع کاربردی enumerate، zip، any و all را مرور کن.
- [ ] شی‌گرایی، ذخیره‌سازی فایل و تست خودکار را تمرین کن.
- [ ] Iterator، Generator، Decorator و Context Manager را تمرین کن.
- [ ] یک Package چندماژولی بساز و تست کن.

## قانون انتشار
فصل‌های ۰۶ تا ۱۱ تا زمان بازبینی مثال‌ها، ترجمه‌های جفت‌شده، شناسه تمرین‌ها و بررسی کیفیت، پیش‌نویس محسوب می‌شوند و فقط روی شاخه بازبینی قرار دارند. وجود محتوا در مخزن به معنی تسلط شخصی نیست.
