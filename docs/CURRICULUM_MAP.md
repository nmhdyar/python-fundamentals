# Python Fundamentals — Curriculum Map

## Foundations (01–05)
Variables and types; conditions and loops; data structures; functions; modules, exceptions, and debugging.

## Intermediate Python (06–08)
- 06 — Object-Oriented Programming
- 07 — File Handling & Data Persistence
- 08 — Testing & Code Quality

## Advanced Python (09–11)
- 09 — Iterators & Generators
- 10 — Advanced Python Concepts
- 11 — Project Structure & Packaging

## Practical Python (separate learning track)
API integration, SQL and databases, Flask and web applications, automation, and portfolio projects are intentionally kept outside the language-focused core curriculum.

## Bilingual rule
Every chapter has paired English and Persian READMEs, matching Python lesson filenames, and five matching exercise IDs. See [TEACHING_STANDARD.md](TEACHING_STANDARD.md).
