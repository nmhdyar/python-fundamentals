# Chapter 02 — Conditions and Loops

This chapter collects the original exercises that are still useful for practicing decisions, iteration, and nested loops. The selected exercises have been renamed and cleaned up for readability. Original versions remain preserved in `archive/early-exercises/`.

## Lessons and exercises

| File | Focus |
|---|---|
| [01 — Conditional Statements](01_conditional_statements.py) | `if`, `elif`, `else` |
| [02 — Iterating with for](02_for_loop_iteration.py) | Iterating over a sequence |
| [03 — Counting with while](03_while_loop_counter.py) | Loop conditions and updating state |
| [04 — Filtering Even Numbers](04_filter_even_numbers.py) | `range()`, modulo, conditions |
| [05 — Combining Conditions](05_combining_conditions.py) | `and` with comparison operators |
| [06 — Accumulating a Sum](06_accumulating_a_sum.py) | Running totals and accumulation |
| [07 — Nested Loop Rectangle](07_nested_loop_rectangle.py) | Rows, columns, nested iteration |
| [08 — Checkerboard Pattern](08_checkerboard_pattern.py) | Nested loops and conditional output |

## How to practice

1. Predict the output before running each file.
2. Change the input values and ranges.
3. Explain why each loop stops.
4. For the pattern exercises, trace the row and column indexes by hand.

> The archive contains the untouched early versions. These chapter files are the organized learning copies.
